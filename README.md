# 🎮 GameZone Retro

README para a atividade desenvolvida no **VS Code**, criando uma página HTML para uma loja fictícia de jogos e consoles clássicos.

## 📌 Sobre a atividade

O objetivo da atividade foi desenvolver uma página simples utilizando **HTML**, apresentando uma loja chamada **GameZone Retro**.

A página contém informações sobre consoles disponíveis, preços de jogos, imagem temática e links.

## 🛠️ Tecnologias utilizadas

* HTML5
* Visual Studio Code
* Navegador Web

## 🎮 Conteúdo da página

A página apresenta:

* 🎮 Nome da loja: **GameZone Retro**
* 🕹️ Lista de consoles disponíveis:

  * Nintendo (NES)
  * Super Nintendo (SNES)
  * Sega Genesis
  * Atari 2600
* 💰 Tabela com jogos, consoles e preços
* 🖼️ Imagem relacionada a jogos retrô
* 🔗 Links para preços e Instagram
* ©️ Rodapé da página

## ▶️ Como executar

1. Abra o projeto no **Visual Studio Code**.
2. Abra o arquivo `index.html`.
3. Execute utilizando o navegador ou a extensão **Live Server**.
4. A página da GameZone Retro será exibida.
